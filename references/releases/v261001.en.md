# v261001 — GPT-6.1 Sol, stronger review controls, and faster diagnostics

Codex Reviewer packages independent, read-only code reviews into a repeatable workflow: explicit scope, evidence-backed findings, structured results, and quality-gate handling.

This release switches every preset to **GPT-6.1 Sol**, requires **stable Codex CLI 0.159.3 or newer**, strengthens tool isolation, and separates quick checks from full environment diagnostics.

## Highlights

- **One default model across presets.** `quick`, `standard`, `deep`, and `ultra` now use `gpt-6.1-sol` with `medium`, `high`, `xhigh`, and `ultra` reasoning respectively. Automatic model fallback has been removed, and retired `gpt-5.5` is rejected. Unavailable models or reasoning capabilities are reported before review starts.
- **Minimum-version repair.** A missing or outdated CLI is installed/upgraded by default using its installation source, then its version is read back. An explicit binary pin, dry run, or disabled updates cannot bypass the minimum version requirement.
- **Stronger tool controls.** Every review disables hooks. Ordinary and bounded reviews explicitly prohibit delegation. Only generic `ultra` allows model delegation, with an agent concurrency limit of 2. Bounded review additionally disables Code Mode and enforces a zero-tool policy.
- **Faster doctor checks.** `doctor` defaults to configuration and stored-credential checks plus the normal capability checks. Use `--full-diagnostics` for the complete environment check; `--diagnostic-timeout` controls its default 90-second limit. Full-diagnostic warnings, failures, and timeouts are recorded separately.
- **Updated event contracts and CI.** CLI 0.159.3 fixtures cover command-start failures, early output, incomplete progress, and complete usage. CI also checks version, model, and tool-control flags.
- **Refreshed operational documentation.** Preset rules, update policy, official sources, and validation boundaries have been synchronized.

## Before you upgrade

Minimum requirements: **Python 3.10+, Git, and stable Codex CLI 0.159.3+**. Authenticate the CLI and confirm your account supports the selected model.

This release changes both the default model and CLI update behavior. If you manage the CLI yourself, use `--codex-bin` or `--no-update-check`; the version minimum still applies. CLI upgrades do not modify the reviewed repository or overwrite your Codex configuration.

For everyday reviews, start with `standard`. Use `deep` for complex or high-value changes. `quick` is triage, not a formal quality gate.

## Install and try it

```bash
git clone https://github.com/BIGWOO/codex-reviewer.git \
  "$HOME/.agents/skills/codex-reviewer"
python3 "$HOME/.agents/skills/codex-reviewer/scripts/codex_review.py" doctor
```

Already installed? Preserve local changes first, then run `git pull --ff-only` from the skill directory.

In your next Codex message:

```text
$codex-reviewer Review my uncommitted changes with the standard preset.
Return only actionable, evidence-backed issues. Do not modify files.
```

## What this adds to official Codex

Official Codex already supports code review, read-only controls, and structured output through its CLI. This community-maintained skill packages scope validation, review policies, result envelopes, repository locks, lifecycle handling, and quality gates into a reusable workflow. It is not an OpenAI product and does not enable the official GitHub PR review bot.

Use official `/review` for an occasional check; use this skill when you want a repeatable review-and-handoff process. No claim of superior model accuracy or lower usage is made. Read-only workspace access does not mean code stays off the configured model service.
